# Development Artifacts

This directory contains planning and decision records used to develop Snarkypuss and its
SnarkyCtl management utility. These files describe requirements, roadmap items, and design
constraints; they are not installation or operator documentation.

- [**SNARKYCTL.md**](SNARKYCTL.md) — management-utility requirements, security constraints,
  implementation phases, and development roadmap.
- [**DECISIONS.md**](DECISIONS.md) — architecture decision records that define the
  requirements baseline.
- [**PLAN10.md**](PLAN10.md) — completed provider-neutral SQLite target-catalogue plan.
- [**UAT10.md**](UAT10.md) — Plan 10 user-acceptance record.

User and administrator documentation is in `docs/`. Begin with the main
[project overview](../README.md), the [Snarkypuss technical reference](../docs/11_ARCHITECTURE.md), or
the [SnarkyCtl installation guide](../docs/03_SETUP_SNARKYCTL.md).
